# R789 – R789 Game (Pakistan)

Official marketing site for **R789** at [r-789game.com.pk](https://r-789game.com.pk).

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS (icon-derived navy / sky blue theme)
- Poppins via `next/font`

## Scripts

```bash
npm run dev
npm run build
npm start
```
